# Expense Tracker

A modern and responsive **Expense Tracker** web application built using **Flask**, **SQLite**, and **Bootstrap 5**. The application allows users to manage their income and expenses, view transaction history, and monitor their financial summary through an intuitive dashboard.

---

## Features

- Add Income and Expense transactions
- Edit existing transactions
- Delete transactions
- View complete transaction history
- Financial Dashboard
  - Total Income
  - Total Expense
  - Current Balance
- Date-wise transaction records
- Category selection
- Form validation
- Responsive Bootstrap 5 UI

---

##  Tech Stack

- **Backend:** Flask (Python)
- **Database:** SQLite
- **Frontend:** HTML5
- **Styling:** Bootstrap 5
- **ORM:** Flask-SQLAlchemy


## Financial Summary

The dashboard automatically calculates:

- Total Income
- Total Expense
- Current Balance

These values update whenever a transaction is added, edited, or deleted.
